## 兩位同學怎麼驗收

先部署最新程式及所需規則。患者用手機、復健師用電腦，確認是同一套 Firebase 專案及已有有效照護關係的兩個測試帳號。

1. 患者首頁填每日感受，選不確定，儲存後重新登入。確認值沒有變成沒有不舒服。
2. 修改當天回報，復健師重新登入個案總覽，確認可以看到最新內容及舊版本。
3. 有進行中的 F01 追蹤訓練日：先核對目標、單筆次數與達標數，再回報辨識或儲存問題。確認回報原因沒有改掉訓練完成量。
4. 自主練習選一個動作，進自行回報。確認勾選框與文字都在卡片內，點文字可勾選。分別試合計、左右，以及時間型動作的秒數。
5. 儲存後返回查看，同一次操作不應出現兩筆。填錯時展開紀錄作廢，確認原量仍保留、狀態變成已作廢；復健師應看得到但不能代改。
6. 若已有 D5 不自動判定提案的測試個案，再走復健師安排 → 患者接受 → 新基準 → 下一週。只看初次評估頁，不代表已進入這段流程；不要為了測試擅改正式資料日期或量測結果。

若失敗，記錄頁面、角色、操作步驟、實際結果、時間與錯誤訊息。不要只寫「沒有資料」，要分辨沒回報、雲端未載入、關係不符、來源不符或紀錄尚未同步。

## 還需要團隊確認的規則

- 自行回報能否作為課表／七日達標證據，需要哪些量與確認。
- 分次練習如何跨紀錄累計、左右與組數如何解讀，哪些情況禁止合併。
- 本人／照顧者聲明、補回報與跨版本資料，各自能用於顯示、比較或推薦到哪裡。
- 無復健師時的接續政策；目前提供連結與重新評估入口，不代表所有情境都已有核准安排。

這些尚未寫成新判定規則。現階段不要把多了回報欄位解釋成已能自動個人化加減量。
