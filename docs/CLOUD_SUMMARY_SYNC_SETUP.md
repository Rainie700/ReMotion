# 週期與摘要跨裝置同步

保留原本 .env.local，不要刪除手機網站資料。

1. 覆蓋本更新檔至專案根目錄。
2. 執行 npm run build。
3. 執行 firebase deploy --only "firestore:rules,hosting"。
4. 手機患者登出、重新登入：載入雲端資料後補傳此患者本機的追蹤週期。
5. 電腦復健師登出、重新登入，進入同一患者的總覽並產生摘要。
6. 按確認摘要，等同步完成；手機患者重新登入後到「數據」查看。

新規則只限制 trackingCycles 與 llmWeeklySummaries：患者讀取自己的資料，復健師依 accepted 照護關係讀取；摘要只由對應復健師建立與更新。其他集合仍沿用既有登入者規則，尚未全面強化，不適合存放真實臨床敏感資料。

摘要顯示「安全備用摘要」不代表 Gemini 連線成功。必須顯示「Gemini 整理」才代表模型輸出成功且通過驗證。App Check 強制執行先保持關閉。

本更新已做本機測試與建置，但沒有登入你的 Firebase 帳號，不能代替正式跨裝置驗收。
