### 每日回報「尚未確認雲端儲存成功」（功能問題）
- **原因**：除了少數已知代碼，所有 Firestore 錯誤都被歸成 `cloud_save_failed`，原始錯誤代碼也沒有留下。因此權限被拒、離線、資料格式錯誤，畫面都一律猜「請確認網路與登入狀態」。
- **修正**（`js/data/dailyTrainingFeedbackService.js`，沒有改安全規則）：
  - 保留並在主控台記錄原始錯誤代碼，依原因分類：
    - `permission-denied` → 權限檢查未通過；
    - `unavailable`／`deadline-exceeded` → 沒有網路；
    - `unauthenticated` → 登入失效；
    - `invalid-argument` → 資料格式問題；
    - 其他 → 不猜原因。
  - 瀏覽器回報離線時直接告知，不讓交易一直重試。
  - 寫入前移除 undefined 欄位。
  - 重送時若發現自己的回報其實已寫入，就視為成功，不顯示衝突。一次交易仍只會新增一個版本。
- 失敗時仍保留輸入，確認寫入成功後才顯示完成。
- **本機模擬器驗證**：
  - 離線：顯示「目前沒有網路連線」，輸入保留，沒有寫入；恢復連線後重送，只有 1 筆回報（revision 1）。見 `browser\RUN_LOG.txt` D1、D2。
  - 權限被拒後重試：見第 3 輪回歸 F1 與重新送出。
- **正式雲端**：沒有驗證。正式專案的規則與網路情況，本輪沒有證據，維持未結案。
