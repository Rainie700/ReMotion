## 改了什麼

### 首頁

由上而下：
1. 簡短問候；
2. **一個主要任務**；
3. 本週訓練／本週紀錄小格（有週期時）；
4. 「今天練習感覺如何？」入口；
5. 本週進度（等級與旅程入口、我的進度、我的成就）；
6. 次要入口。

主要任務沿用既有的共用狀態：週期卡用 `renderTrackingCycleCard`，首次安排用 `loadInitialPlanNotice`，旅程與下一階段的出口也是既有的，不另寫判斷。

| 狀態 | 主要任務 |
|---|---|
| 尚未建立安排 | 開始自主復健 |
| 待檢視（有復健師） | 待復健師檢視 → 查看待檢視安排（並說明系統不會另外通知） |
| 待檢視（沒有復健師） | 說明目前無法完成檢視，可查看說明與邀請碼；不暗示有人處理 |
| 待接受 | 復健師已確認，等待你接受 → 查看確認安排 |
| 待新基準 | 已接受，請完成新的基準評估 → 開始第一週基準評估；下一週期的新基準沿用週期卡原有入口 |
| 本週進行中 | 開始今日訓練（或繼續、已完成） |
| 已接受但尚未啟用 | 原本的週期仍是主要任務；下方一行「另有首次訓練安排｜已接受，尚未啟用」＋查看原本的週期 |
| 安排載入中／失敗 | 「正在載入你的訓練安排…」／「暫時無法載入…這不代表沒有安排」＋重新載入；不會顯示成開始自主復健 |

從首頁移除的內容：
- 整份回報問卷；
- 每個動作的目標與單筆紀錄；
- 資料歸屬與讀取範圍的長篇說明；
- 自行回報的歷史紀錄（移到「數據 → 訓練紀錄」）；
- 沒有復健師安排時的空白「今日復健」卡。

### 回報

- **入口**：首頁和本週訓練頁都只有一行入口，「填寫回報」，已回報時是「今日已回報＋查看／更新」。
- **底部面板**：
  - 標題與回報對象；
  - 分步作答，顯示第幾步；
  - 保留原有選項，不預選答案；
  - 上一步會保留答案；
  - 關閉時保留未送出的內容，入口顯示「繼續填寫／有尚未送出的回答」；
  - 送出成功後才顯示完成；
  - 失敗時保留內容，可重新送出；
  - 送出中不能再按，連點也只存一筆。
- **面板行為**：
  - 面板放在頁面之外，開啟時不重畫頁面；
  - 背景不捲動，關閉後回到原位置；
  - 依可視區域調整高度，鍵盤開啟時輸入框與送出鈕仍可操作。
- **歸屬沒有改**：
  - 首頁的吃力、不適、備註是一般回報；
  - 首頁的未完成原因會顯示它對應的週期目標；
  - 本週期回報帶有該週期（`subject`），才算是這個週期的完整回報；
  - 歷次回報在「查看／更新」裡，不在首頁展開。

### 訓練分頁

- 有週期時，最上方是「本週訓練」卡片，返回會回到訓練分頁。
- 「探索與練習」：坐站練習（連到第 1 輪的頁面，返回直接回訓練分頁）、六大功能構面，以及自主練習與訓練紀錄。
- 坐站練習仍不會建立週期，也不計入完成天數。
- 底部導航：本週訓練、從訓練分頁進入的功能構面、F01 與坐站練習，都標示「訓練」。

### 順帶修正的缺陷（驗收時發現）

- `storageService.hydrateCloudForUser` 在載入核心資料時，會**清空**可選集合的載入狀態，這段時間讀起來像「沒有雲端」，首頁可能短暫顯示成沒有安排。現在一開始就標示為載入中。
- 從功能構面進入 F01 後按返回，功能構面頁會忘記原本是從哪裡進來，再按返回會回首頁。已修正。

第 3 輪驗收的內容：

2. **一般回報**：
   - 開啟時沒有預選，背景鎖住；
   - 上一步會保留答案；
   - 未完成原因標示對應目標；

3. **本週期回報**：頂端標示週期；存入時帶有 `subject`，一般回報不受影響。

6. **入口與返回**：坐站練習與六大功能構面從訓練分頁進出都正確；本週訓練從訓練分頁進入會返回訓練分頁，導航標示「訓練」。
