## 入口為什麼找不到（依程式核對）

- 固定練習本身沒有任何 patient00、Demo、評估完成或週期的條件。
- 原本唯一的路徑是「首頁 → 開始自主復健 → 功能構面 → F01 → C」。**有進行中週期時，首頁的「開始自主復健」卡會被「本週功能追蹤」卡取代**，這條路就不見了。
- 「訓練」分頁（我的復健課表）原本沒有任何 F01 入口。
- 修正：訓練 → 快速功能加上「F01 下肢功能」（一律顯示，不看帳號、評估、週期或紀錄），從那裡進 F01 頁的「返回」會回到訓練頁。首頁那條路不變。

### 「兩個開啟鏡頭」

在本機（390／430／1280）與線上版本中，準備頁的頁面結構裡都只找到**一個**「開啟鏡頭」，無法重現兩個按鈕。可能的來源有兩個：
- 原本介紹頁的「開始固定練習（相機計次）」與準備頁的「開啟鏡頭」連續出現，形成兩次開相機；
- 原本黏在內容底部的按鈕列，捲動時會蓋住其他內容。

這兩者本輪都已改掉：介紹頁只有「開始準備」，準備頁按鈕移出捲動區。瀏覽器驗收在三種寬度與其他動作的準備頁，都確認只有 1 個。
